🔐 File Secure System

Upload files, store them safely, and prove they were never modified — using SHA-256 hashing and a simple blockchain.

  • ✅ Secure registration & login (bcrypt + JWT)
  • 📤 Upload files up to 5 MB
  • #️⃣ Every file gets a SHA-256 fingerprint
  • ⛓️ Fingerprints are stored in a simple blockchain
  • 🔎 Verify anytime that a file was not modified
